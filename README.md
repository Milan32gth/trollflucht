# Trollflucht

Ein Browser-Platformer mit zwölf normalen und drei geheimen Levels. Geheime Levels werden nach dem normalen Levelpfad freigeschaltet. Normale Level bringen einmalig 1 Token, geheime Level 5 Token. Vier kostenpflichtige Bonuslevel kosten 20, 24, 28 und 32 Token. Zusätzliche Trolle kosten 8, 12 oder 16 Token. Kaufbare Boni: Sprint (18 Token, 45 % schneller) und Schwere Stiefel (16 Token, 30 % langsamer); Normaltempo ist jederzeit wählbar.

Im Shop-Menü können bis zu fünf benannte Speicherplätze angelegt werden. Ein neuer Slot kostet 20 Token und jeder manuelle Speichervorgang ebenfalls 20 Token. Der siebte Tod im Profi-Modus setzt den Spielfortschritt und die Slots zurück. Deutsch und Englisch, Teilen, Musik und Patchnotes sind ebenfalls enthalten. Am unteren Spielrand steht der Hinweis, die Seite nach Updates neu zu laden.

## Deployment

Statische Website. Die öffentliche Version läuft auf Render; Änderungen werden über das GitHub-Repository veröffentlicht.

## Spielen

Öffne `index.html` in einem modernen Browser. Für die installierbare Web-App-Version muss die Seite über HTTPS bereitgestellt werden.
