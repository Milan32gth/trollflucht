# Trollflucht

Ein kleines Browser-Platformer-Spiel mit sechs Levels und Touch-Steuerung.

## Deployment

Dieses Repository ist als statische Website gedacht. Auf Render lautet der
Build-Befehl `true` und der Publish-Pfad `.`. Nach dem Push auf den
Standardbranch kann Render Änderungen automatisch veröffentlichen.

## Spielen

Öffne `index.html` in einem modernen Browser. Für die installierbare
Web-App-Version muss die Seite über HTTPS bereitgestellt werden.
