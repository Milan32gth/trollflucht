# Trollflucht

Ein Browser-Platformer mit zwölf normalen und drei geheimen Levels. Die geheimen Levels werden nach dem normalen Levelpfad freigeschaltet und erscheinen nicht im normalen Levelpfad. Jedes Level hat eine eigene düstere Musikvariation; am Ende erscheint „Yay! – cool dass du es geschafft hast“.

## Deployment

Statisches Spiel. Auf Render sind `true` als Build-Befehl und `.` als Publish-Pfad eingestellt. Dieses Repository wird über die öffentliche Git-URL eingebunden; Änderungen werden in Render manuell veröffentlicht.

## Spielen

Öffne `index.html` in einem modernen Browser. Für die installierbare Web-App-Version muss die Seite über HTTPS bereitgestellt werden.
