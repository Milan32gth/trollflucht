# Trollflucht

Ein Browser-Platformer mit zwölf normalen und drei geheimen Levels. Geheime Levels werden nach dem normalen Levelpfad freigeschaltet. Normale Level bringen einmalig 1 Token, geheime Level 5 Token. Vier kostenpflichtige Bonuslevel kosten 20, 24, 28 und 32 Token. Zusätzliche Trolle kosten 8, 12 oder 16 Token. Kaufbare Boni: Sprint (18 Token, 45 % schneller) und Schwere Stiefel (16 Token, 30 % langsamer); Normaltempo ist jederzeit wählbar.

Im Shop-Menü können bis zu fünf benannte Speicherplätze angelegt werden. Ein neuer Slot kostet 20 Token und jeder manuelle Speichervorgang ebenfalls 20 Token. Im Profi-Modus setzt der siebte Tod den laufenden Fortschritt und Token zurück; manuell gespeicherte Slots bleiben als Backups erhalten. Deutsch und Englisch sowie zehn weitere Sprachen sind enthalten; die Sprachauswahl ist durchsuchbar. Teilen, Musik, übersetzte Patchnotes und ein Support-Button zum Vorbereiten einer Fehler-Mail sind ebenfalls enthalten. Neue Versionen werden beim Besuch automatisch übernommen und die Seite lädt sich einmal neu. Am unteren Spielrand wird außerdem an Profi-Backups erinnert.

## Deployment

Statische Website. Die öffentliche Version läuft auf Render; Änderungen werden über das GitHub-Repository veröffentlicht.

## Spielen

Öffne `index.html` in einem modernen Browser. Für die installierbare Web-App-Version muss die Seite über HTTPS bereitgestellt werden.
