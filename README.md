# Trollflucht

Ein Browser-Platformer mit zwölf kostenlosen Hauptleveln und drei geheimen Levels. Die geheimen Levels werden nach dem normalen Levelpfad freigeschaltet und erscheinen nicht im normalen Levelpfad. Zusätzliche Trolle kosten 3, 5 oder 8 Token. Normale Level geben beim ersten Abschluss je 1 Token, geheime Level je 5 Token. Der neue Bonuslevel „Abgrundspfad“ kostet 10 Token. Deutsch und Englisch, Teilen, Patchnotes sowie die Modi Leicht und Profi sind im Spiel enthalten. Im Profi-Modus setzt der siebte Tod den gesamten Spielfortschritt zurück.

## Deployment

Statisches Spiel. Auf Render sind `true` als Build-Befehl und `.` als Publish-Pfad eingestellt. Änderungen werden nach dem Push auf GitHub veröffentlicht.

## Spielen

Öffne `index.html` in einem modernen Browser. Für die installierbare Web-App-Version muss die Seite über HTTPS bereitgestellt werden.
